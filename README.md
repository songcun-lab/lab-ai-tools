# lab-ai-tools

> AI 工具实测 + 判断框架 —— 不只记录「我用了什么」，更记录「我凭什么判断它好不好」。

这是 [Songcun Lab](https://github.com/songcun-lab) 下专门做 **AI 工具评测与选型** 的仓库。
核心理念：把零散的「试用体验」连接到一套**可复用的判断标准**上，避免凭感觉跟风。

## 📁 目录结构

```
lab-ai-tools/
├── README.md
├── workflows/
│   └── how-i-judge-cli-ai-tools.md   # 我评判 CLI 类 AI 工具的标准
└── experiments/                       # 单个工具的实测记录（陆续补充）
```

> `experiments/` 目前是空的，作为后续逐个工具实测的归档位。每完成一次评测就新增一个文件。

## 🧭 阅读顺序

1. 先看 [`workflows/how-i-judge-cli-ai-tools.md`](workflows/how-i-judge-cli-ai-tools.md)，了解判断标准；
2. 再看 `experiments/` 里具体工具是怎么按这套标准被打分的。

## 🧪 一次实测建议包含

- 工具名称 / 版本 / 用途
- 实际任务场景与操作过程
- 按判断框架逐项打分
- 结论：留用 / 观望 / 弃用，以及理由
